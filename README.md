# My Blog

A simple responsive blog application built using Node.js, Express.js, and EJS.

## Features

- Create blog posts
- View all blog posts
- Edit blog posts
- Delete blog posts
- Custom 404 error page
- Responsive design for desktop and mobile
- Reusable EJS header and footer partials

## Tech Stack

- Node.js
- Express.js
- EJS
- HTML
- CSS
